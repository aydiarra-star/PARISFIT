# Préparation à l'expertise indépendante

## Décision **B — prêt uniquement pour une expertise préliminaire**

Une revue documentaire sérieuse est possible : sources figées et hashées, configurations, questions anatomiques explicites, intégrité C3D établie auparavant, versions d'export et journaux de traitement retrouvés, lacunes bornées. Cela exclut C (dossier inexploitable même préliminairement).

A n'est pas justifié : absence de preuve individuelle suffisante de pose/calibration/traitement des gaps, synchronisation physique non démontrée, environnement auteurs pas totalement reconstitué, sorties dynamiques localisées mais non intégralement contextualisées. Un journal ou la présence de fichiers ne ferme pas ces lacunes.

L'expert préliminaire pourrait contester la portée du log original, les contradictions de guide, la compatibilité modèle/protocole, les limites de timing et prioriser les pièces manquantes. Une expertise complète nécessite la traçabilité de séance, les versions/builds exacts, les corrections effectuées, la pose et la synchronisation ainsi que l'interprétation des résultats originaux sélectionnés. Aucun seuil universel n'est créé.
