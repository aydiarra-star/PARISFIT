Avons-nous assez d’informations ?

Non. Utilisation actuelle pour S01/P001 : REFUSÉE. Aucun lien anatomique CSV→MarkerSet n'est confirmé par documentation. Cela ne démontre pas que le modèle est biologiquement incompatible : cela empêche son utilisation rigoureuse en l'état.

IK NON TESTÉE. Aucun renommage automatique, centre inventé ou transfert Rocketbox. Modèle générique ≠ modèle S01.

Ce que l’audit distingue

Le dépôt déclare37marqueurs de laboratoire dans le modèle ; le XML en expose66. Des correspondances sémantiques sont plausibles, mais les mains et la tête ne disposent pas de leurs marqueurs dans ce template. Les abréviations de centres articulaires ne doivent jamais absorber des marqueurs cutanés.

Le README décrit explicitement un modèle générique. Les masses et six facteurs de scaling de S01 sont disponibles dans participants.csv ; leur existence ne constitue pas un modèle individualisé ni une procédure de scaling complète.
