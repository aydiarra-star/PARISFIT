Pourquoi ne pas retargeter ces chaînes ?

La distance entre landmarks de cuisse varie d'environ80mm. Fixer leur longueur déplace les endpoints : résidu RMS46,5mm pourH1 et86,8mm pourH2. Le fit de bassin de2,1mm ne localise pas les centres de hanche.

OpenSim4.6 charge le template :22corps,39coordonnées,66marqueurs. Aucun nom strictement identique aux37labelsCSV. La correspondance et le scaling ne sont pas validés ; le chargement n'est pas une IK du sujet.
