# Choix de capture — état vérifié le 27 novembre 2026

**Voie recommandée pour l'essai : deux vues simultanées calibrées, traitement local, source consentie.** Résultat attendu : réduire l'ambiguïté de profondeur, non garantir un coach premium. Pas de service souscrit, pas de crédits consommés. Dépense de cette phase : 0 €.

| Solution | Matériel et coût réel à prévoir | Droits et limites | Décision |
|---|---|---|---|
| MediaPipe Pose local | Un ordinateur et une vidéo existants : pas de frais API locaux ; temps de calcul, opérateur et caméra restent des coûts | [33 repères image/3D estimés](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker), pas positions mesurées ni orientations complètes des pieds/doigts ; modèle/SDK à figer séparément. Code Apache2 dans le dossier phase5 | Baseline possible après consentement. Pas de nouvelle extraction exécutée sans vidéo |
| Reconstruction locale multi-vues / FreeMoCap | 2 caméras minimum pour triangulation, 3 recommandées par la [documentation actuelle](https://docs.freemocap.org/), supports fixes, mire imprimée mesurée, ordinateur. Si tout est déjà disponible : aucun achat requis ; sinon devis/inventaire avant dépense | Calibration et synchro indispensables. Licence des composants/version choisie à enregistrer ; phase5 étudiait AGPL3. Le logiciel libre n'accorde pas de droits sur le participant. Aucun bundle nouveau qualifié ici | Prioritaire, calibration/erreur de reprojection à contrôler. Pas une capture optique instrumentée |
| Reconstruction monoculaire 3D locale | Matériel moindre ; certains modèles nécessitent GPU/poids et SMPL | Profondeur, occlusion, échelle et rotations ambiguës. Code libre ≠ poids/modèle de corps commercial. Les refus AMASS/WHAM/SMPL antérieurs ne sont pas levés | Non retenue comme preuve premium sans droits et validation indépendante |
| OpenCap | [Site primaire](https://www.opencap.ai/) : multi-caméra 2+ iPhones et un terminal web ; option monoculaire beta ; traitement cloud | « Free for Research » ne prouve pas un droit commercial. Consentement cloud et droits logiciel/modèles/service à vérifier. Estimation de forces ≠ mesure instrumentée pour notre prise | Aucun compte ni upload ; pas retenu pour ce pipeline commercial local |
| Capture optique instrumentée | Studio, plusieurs caméras IR, marqueurs, opérateur ; pression/forces nécessitent matériel supplémentaire. Tarif non vérifié : devis nécessaire | Contrat sur capture, droits d'image, réutilisation des données, export brut, solveur et confidentialité. Occlusions/solving restent possibles | Potentiellement meilleure observabilité ; aucun budget/achat autorisé, aucun devis sollicité |
| Capture inertielle | Combinaison/capteurs, calibration et opérateur ; coût matériel/location à chiffrer | Dérive de position, appuis/mains non garantis ; contrat du fournisseur et export à vérifier | Pas de matériel disponible attesté, non exécutée |
| Blender | Logiciel gratuit ; machine compatible et temps de calibration/nettoyage nécessaires | [GPL logiciel, œuvres utilisables commercialement](https://www.blender.org/about/license/), droits des données toujours distincts. Ce n'est pas un dispositif de capture | Étape de retargeting préparée ; blocage système actuel détaillé dans BLENDER.md |
| Bibliothèques gratuites/commerciales | Étude phase7 : CMU, Quaternius, Mixamo, MoCap Online | Gratuit ≠ droit de redistribuer source/GLB dans une PR publique. Sources NC exclues. CMU connu mais résultats insuffisants | Aucune ancienne animation rebaptisée capture dédiée ; aucun pack acheté |

Les prix de studio/matériel/services ne sont pas inventés. Avant décision, dresser l'inventaire disponible et obtenir l'autorisation pour toute dépense. Le temps professionnel, stockage sécurisé et captation ne deviennent pas gratuits parce que le logiciel l'est.

Sources consultées : pages primaires liées ci-dessus ; compléments licences et corpus dans `../phase7/DATASETS.md`, `../phase7/licenses/` et `../phase5/SOLUTIONS.md`. Aucune promesse de précision millimétrique à partir du seul marketing d'un outil.
